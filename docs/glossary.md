# Glossary

| Term | Definition | Avoid |
| --- | --- | --- |
| Member | A person who borrows book copies and has a member profile linked to a Member user account. | |
| Librarian | A person who administers the catalog and member accounts and reviews loans using a Librarian user account. | |
| User account | The starter's authentication identity, with credentials and a Member or Librarian role. | |
| Member profile | The Member's domain record, distinct from and linked to the user account. | |
| Book | A catalog entry describing a title in the library's collection. | |
| Book copy | An individual copy of a Book that can be borrowed. | |
| Catalog | The library's records of Books and their book copies. | |
| Loan | The record connecting a Member profile and a book copy with borrowing and return times. | |
| Active loan | A Loan for which the book copy has not been returned. | |
| Completed loan | A Loan for which the book copy's return has been recorded. | |
| Lending history | The retained completed loans showing who borrowed book copies and when. | |
