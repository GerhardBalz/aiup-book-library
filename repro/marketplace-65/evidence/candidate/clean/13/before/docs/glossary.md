# Glossary

| Term | Definition | Avoid |
| --- | --- | --- |
| Member | A person with a User Account and a Member Profile who can borrow and return Books. |  |
| Librarian | A person with a User Account who manages the Catalog and creates User Accounts for Members. |  |
| User Account | The sign-in identity for a Member or Librarian. |  |
| Member Profile | The domain record that links a Member’s User Account to that Member’s Loans. |  |
| Catalog | The collection of Books listed for discovery in Book Library. |  |
| Book | A record describing a work by title, author and ISBN that can represent multiple Copies. When a Book with Loan History is withdrawn from the Catalog, its record and Loan History are retained. |  |
| Copy | One lendable instance of a Book. |  |
| Loan | A record of a Member borrowing a Book, including when it was borrowed and, once returned, when it was returned. |  |
| Active Loan | A Loan whose Book has yet to be returned. |  |
| Loan History | The record of who borrowed which Books and when, including Loans that have ended. |  |
