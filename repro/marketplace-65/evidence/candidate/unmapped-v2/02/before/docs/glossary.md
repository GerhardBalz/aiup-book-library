# Glossary

| Term | Definition | Avoid |
| --- | --- | --- |
| Active Loan | A Loan whose Book Copy has yet to be returned. | |
| Book | A bibliographic record that describes what Members can borrow. A Book can have one or more Book Copies. | |
| Book Copy | A lendable instance of a Book. It is available to borrow when it has no Active Loan and is offered in the Catalog. | |
| Catalog | The collection of Book records offered by the library for discovery and borrowing. | |
| Librarian | A person who manages the Catalog, creates Member Accounts, and monitors Active Loans. | |
| Loan | The record that associates a Member with a borrowed Book Copy and records when borrowing and return occur. | |
| Loan History | The retained record of borrowing and returns, including completed Loans. | |
| Member | A person enrolled at the library who can borrow and return Book Copies and see their own Loans. | |
| Member Account | A User Account that lets a Member sign in and use Member functions. | |
| User Account | The sign-in identity for one Member or Librarian, with a role that governs access to library functions. | |
