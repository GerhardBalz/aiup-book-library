# Book Library requirements baseline

The published AIUP skills are ordinary repository files in `.agents/skills`.
Their exact versions, source revisions and file hashes are in
`baseline/runtime.json`. No package installation is needed to discover them.

Start from `docs/vision.md` and `docs/architecture.md`. Follow the requested
skill's normal workflow, ask the user for material decisions and keep approval
with the responsible person. No earlier run's answers, approvals or defaults
are carried into this baseline.
